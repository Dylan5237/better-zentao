# CR-007 工作台按月查看与读取缺口

| 六步需求卡 | 约定                                                                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 意图       | 从工作台直接查看本月或其他月份，知道哪些统计缺少禅道来源，去掉演示入口。                                                                               |
| 口径       | 自然月按团队业务时区计算。任务按排期与月份重叠，缺日期的任务单列；需求看月度活动、关联计划或执行。已选发布版本、按编号打开的需求详情使用对象自身范围。 |
| 数据       | 使用现有已投影的禅道数据。排期先筛选重叠或日期不完整的执行，再按叶子任务日期统计。历史月显示当前可见记录。                                             |
| 规则       | 保留禅道职责权限、叶子计数、计划归属和数据缺口口径。显式拒绝时忽略同一响应中的后续内容。「待定」保留为空日期。                                         |
| 能力       | 顶部统一切月、按月复用快照、保留手动同步、显示执行权限缺口。评审说明、一句话助手、评审拍板退出正式入口。                                               |
| 验收       | 默认显示本月，切月重新计算列表与统计，排期匹配自然月日历。同一查询切月使用不同快照。不读拒绝响应携带的后续数据。「待定」计划不影响其他记录。           |
