# CR-006 门户本地快照、手动同步与禅道详情链接

| 六步需求卡 | 约定 |
| --- | --- |
| 意图 | 重开和切换已读页面时立即显示上次的数据，按需同步，并从链接进入对应禅道对象。 |
| 口径 | 顶部「同步本页」按当前页面、标签和筛选读取，详情抽屉单独支持同步。快照时间可从同步按钮查看。 |
| 数据 | SQLite 只保存经过既有工具输出校验的报表。后台探测只读取本人任务及研发需求待办的首页摘要。 |
| 规则 | 缓存按实例、账号、职责、配置和查询条件隔离。角色授权在读取快照前检查。后台探测只提示变化，写入和回执继续实时处理。 |
| 能力 | 已读视图缓存、同查询并发合并、后台变化提示、手动同步、网络失败时保留上次可用报表、按实例路由生成禅道详情链接。 |
| 验收 | 重启后打开已读视图不再读取完整报表。每五分钟最多发起一轮抽样，每轮读取两个列表的第一页。检测到变化时保留页面内容，由用户点击同步。需求、用户需求、任务和 Bug 跳转保留对象编号。 |

待办抽样覆盖本人首页的记录和计数。完整团队、排期、发布、风险和较后分页的变化，可通过手动同步读取。快照保留七天，每个实例和账号下最多保留 128 条。
