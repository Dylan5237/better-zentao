# CR-003 单人门户首次使用

| 六步需求卡 | 约定 |
| --- | --- |
| 意图 | 使用者从本机入口打开工作台，已经配置的内容直接复用，只填写缺项。 |
| 口径 | 延续 CR-002 的八种职责和账号对照表。首次使用时，本机使用者可为已通过禅道验证的本人勾选一项或多项职责。已有映射直接进入工作台。 |
| 数据 | 复用当前实例、账号和已有凭据。缺少实例地址时在登录页填写。缺少团队文件时以空表开始。产品、团队和人员目录不作为进入工作台的前置条件。 |
| 规则 | 本机启动入口用于识别首次配置者。普通登录须按既有账号映射授权。保存职责只更新本机对照表中当前账号的分配，保留其他字段、其他人及 QA_LEAD。过期的表单不能覆盖新配置。 |
| 能力 | 在门户内保存并应用职责，支持兼任和稍后修改。继续沿用现有身份验证、业务服务和操作确认。 |
| 验收 | INIT-01 已配置凭据时从本机启动入口进入；INIT-02 空配置在同一登录页完成；INIT-03 本人勾选并保存后立刻进入工作台，刷新与重启保留选择；INIT-04 普通账号与跨站请求不能修改分配，写入异常可恢复。 |

## 浏览器验收

2026-11-25 在隔离目录启动本机门户，Edge 使用假禅道完成首次登录。在 390 像素宽的页面勾选研发和测试两项职责后进入工作台，再从“我的职责”取消测试。刷新和重启后，研发工作台仍可直接进入。已有凭据的场景同时验证了启动器交接页面、同一标签页重新打开启动链接，以及退出后再次启动。
