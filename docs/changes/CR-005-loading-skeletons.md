# CR-005 异步读取时的局部骨架屏

| 六步需求卡 | 约定 |
| --- | --- |
| 意图 | 在等待数据时看清页面会出现哪些内容，继续使用已就绪的导航、筛选和操作。 |
| 口径 | 沿用伏羲第 11 版就绪界面。只在数据所属的区域显示骨架；快响应在 120 毫秒内完成时直接呈现结果。 |
| 数据 | 所有门户读取、配置文件导入，以及预览和确认后返回的计划与回执。 |
| 规则 | 保持身份与角色隔离，旧请求不能覆盖新内容。保留原有空态、错误、数据缺口、写入确认和恢复语义。 |
| 能力 | 复用同一套占位原语、轻柔透明度脉冲、主题变量及减少动态效果偏好。 |
| 验收 | 离线模拟极快和慢速响应、失败、空结果、切换与关闭，核对就绪结构、键盘控件和窄屏。 |

## 入口清单

| 场景 | 数据区域 | 文件 |
| --- | --- | --- |
| 启动、登录、退出与会话恢复、职责重读及保存 | 会话入口、验证反馈、职责选项和反馈 | `web/index.html`、`web/app.js` |
| 角色、档位、研发团队切换 | 各工作台的指标、列表、卡片与原生表格 | `web/workbench-page.js`、`web/meridian-home-native.js`、`web/meridian-home-controls.js` |
| 提需、需求流转、详情与进度卡 | 待关联/受理区、设计看板、需求台账、详情抽屉 | `web/daily-pages.js` |
| 拆解排期和发布风险 | 队列、矩阵、门禁、风险、计划与迭代 | `web/management-pages.js` |
| 快速检索及一句话助手 | 远程命中列表、助手答复 | `web/meridian-shell.js`、`web/review-page.js` |
| 导航计数和工具弹窗 | 独立徽标、十种只读工具的查询与刷新结果 | `web/app.js`、`web/read-views.js` |
| 写入 | 计划预览、确认、恢复、查询回执 | `web/write-views.js` |
| 独立配置编辑器 | 从所选 JSON 文件更新的配置预览 | `src/adapters/cli/render/config-editor-html.ts` |

同步切换的评审说明、评审拍板、职责内存筛选和本地命令可立即操作。后台会话校验保留已显示页面；台账沿用既有的查询上限和截断提示。终端启动器及 CLI 的进度输出属于命令行界面。
