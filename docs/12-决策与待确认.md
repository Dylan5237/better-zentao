# 12 决策与待确认

> 本文记录三类事项：
> 1. **ADR（已定架构决策）**：编码与评审的前提，修改需要新 ADR。
> 2. **待评审决策**：需要团队或领导拍板的规范与方案选择。
> 3. **待确认参数 / 待验证能力**：需要具体数值、人员或实测结果。
> 状态流转：提议 → 接受 / 拒绝 / 被替代（注明替代编号）。

**ADR-17 版本取舍（2026-11-20）**

- Node 24 于 2026-10-20 进入维护期 LTS，计划支持到 2028-04-30。Node 26 自 2026-10-28 起处于活跃 LTS。P0 在现有 24.x 基线上交付，24.11.0 用于兼容性下限验证，团队安装使用最新 24.x 补丁。[Node.js 发布组时间表](https://github.com/nodejs/Release#release-schedule) · [24.11.0 发布记录](https://nodejs.org/en/blog/release/v24.11.0)
- `<25` 把已承诺支持的范围限定在通过测试的 24.x 大版本。计划在 24.x 支持期结束前迁移到 26 LTS。届时先核对依赖及内置 SQLite 的行为，在 Windows 验证拟定的 26.x 最低版本与最新补丁，跑通离线门禁、CLI 和 MCP 握手，经项目负责人确认后再更新 `engines`、CI 与安装说明。
